# Trellis 中文化、aiotieba 对齐定位与自动提交

## 目标与用户价值

将本项目 Trellis 相关的人类可读内容统一为简体中文，使维护者与后续 AI 会话直接使用中文理解和维护项目。明确 AioTieba4DotNet 的核心定位：参考并对齐 [aiotieba Python 版](https://github.com/lumina37/aiotieba)，作为面向 C#/.NET 使用者的实现，支持其在不同宿主和使用场景下调用贴吧功能。

按用户补充要求，将检查通过后自动完成本地 Git 提交设为项目常规工作流，减少重复的提交确认。

## 已确认背景

- 用户已明确要求 Trellis 人类可读内容中文化，并确认创建本任务进入规划。
- 当前本地工作流、规范、代理定义、技能、脚本说明和历史任务资料中仍有英文；前次规范初始化还明确要求英文。本任务将建立新的中文规则，同时准确保留历史记录的原意。
- 现有代码、公共接口文档及对齐台账是当前实现事实的依据；项目目标不能被写成已经完整对齐上游的结论。
- 工作区已有未提交的 Trellis 初始化文件和根 `AGENTS.md` 改动，实施必须在它们的现状上修改并保留无关内容。
- 关键现状证据：`.trellis/spec/frontend/index.md:5` 与 `.trellis/workspace/index.md:125` 要求英文；`.trellis/scripts/common/workflow_phase.py:38,77-80` 和 `.codex/hooks/session-start.py:468` 依赖英文阶段标题；`add_session.py:100-101,165,1037-1047` 依赖英文日志字段。
- `docs/related/parity.md:16` 将当前对齐基线固定为 `v4.6.4` / `04f8e431f87507a6228b42061c70d298b34317ff`；本轮保持该基线。完整来源见本任务两份研究文档。
- `.trellis/workflow.md:626-650` 当前要求提交前再次确认；`common/config.py:118-136` 的 `session_auto_commit` 仅覆盖日志和归档，不能单独满足用户新增的自动工作提交需求。

## 需求

### R1：本地 Trellis 可读内容中文化

覆盖根 `AGENTS.md` 的 Trellis 说明、本地 `.trellis/` 文档与配置说明、现存 Trellis 技能及其引用说明、Codex Trellis 代理与钩子中的说明和提示，以及本地脚本持有的人类可读注释、帮助、提示和模板文本。任务标题、说明、上下文原因、会话记录正文同样使用中文。

中文化不改变技术名称、文件路径、命令参数、代码标识符、接口名称、配置键、状态枚举、结构化输出字段、哈希、真实提交消息和机器消费的定位标记；必要的兼容性标签保留原文并配中文说明。

### R2：后续维护持续使用中文

后续需求、设计、执行计划、研究、检查和会话记录的自然语言默认使用中文。更新现有“规范使用英文”等冲突规则，并在项目自有规范中记录 Trellis 升级后的中文化保留与复核方式。

### R3：确立 aiotieba 对齐与 C# 库定位

将 aiotieba 作为功能、参数含义、结果语义和边界行为的上游参照。后续涉及公共功能的工作必须记录上游版本或提交、对应 Python 接口、C# 公共入口、已知差异及验证证据；沿用现有台账归属，不另造相互冲突的实现清单。

在保持可对照性的同时遵循 C#/.NET 习惯；不同宿主场景共享库的公共能力与组合方式。准确区分既有支持范围、希望达到的对齐目标、已验证能力与待实现差异。

### R4：兼容性与交付证据

中文化后，Trellis 阶段查询、任务状态和上下文读取、代理说明、结构化配置及本地链接保持可用。验证聚焦文档与工作流，不以构建或在线请求证明接口已经对齐。

### R5：自动执行本地 Git 提交

主会话在本任务及后续已授权任务完成相关检查后，自主审阅差异、按任务范围暂存并提交，无需再向用户询问是否提交。提交标题采用现有 Conventional Commit 类型前缀与中文说明。子代理完成实施和检查后回报，由主会话统一提交。

工作提交先于任务归档、会话记录提交；归档与会话自动提交继续启用，说明使用中文。已有其他工作、凭据、运行缓存和无关暂存内容不能被夹带。没有变更不生成空提交；检查失败则先修复或明确报告阻碍。自动提交权限不扩展到远程推送、改写历史或跳过检查。

- [x] AC5（R4）：记录实际检查结果、外部 CLI 文本边界及保留项；业务代码、生成代码和线上服务状态不受影响。

- [ ] AC7（R5）：隔离验证证明归档/会话提交不会带入无关暂存文件；本任务完成后提供真实提交哈希、检查结果及剩余工作区状态。

## 范围外

- 本轮不补齐或改造 C# 业务接口，不进行全量上游接口差异审计，不调整现有 .NET 版本支持承诺。
- 不翻译与 Trellis 无关的整个产品文档站、第三方依赖、全局 Trellis 安装或 Git 历史。
- 不调用在线测试、不使用账号或凭据访问贴吧、不重新生成 protobuf、不安装依赖或升级 Trellis。
- 不手工改写模板哈希或会话运行状态来掩盖本地定制。
