> 汇总所有开发者与 AI 代理协作的工作记录

---

## 概览

此目录跟踪本项目所有开发者与 AI 代理协作的记录。

### 文件结构

```
workspace/
|-- index.md              # 本文件：总索引
+-- {developer}/          # 各开发者的目录
    |-- index.md          # 含会话历史的个人索引
    |-- tasks/         # 任务文件
    |   |-- *.json        # 活动任务
    |   +-- archive/      # 按月归档的任务
    +-- journal-N.md     # 日志文件（依次编号：1、2、3……）
```

## 入门

### 新开发者

运行初始化脚本：

```bash
python3 ./.trellis/scripts/init_developer.py <你的名称>
```

此操作将：
1. 创建身份文件（由 Git 忽略）
2. 创建进度目录
3. 创建个人索引
4. 创建初始日志文件

### 再次参与开发

1. 获取开发者名称：
   ```bash
   python3 ./.trellis/scripts/get_developer.py
   ```

2. 阅读个人索引：
   ```bash
   cat .trellis/workspace/$(python3 ./.trellis/scripts/get_developer.py)/index.md
   ```

## 规范

### 日志文件规则

- 每个日志文件**最多 2000 行**
- 达到上限时创建 `journal-{N+1}.md`
- 创建新文件时更新个人 `index.md`

### 会话记录格式

每次会话应包含：
- 摘要：一行说明
- 分支：开展工作的分支
- 主要变更：修改了什么
- Git 提交：提交哈希和说明
- 后续步骤：接下来要做的事情

---

## 会话模板

记录会话时使用以下模板：

```markdown
## 会话 {N}: {标题}

**日期**: YYYY-MM-DD
**任务**: {任务名称}
**分支**: `{分支名称}`

### 摘要

{一行摘要}

### 主要变更

- {变更 1}
- {变更 2}

### Git 提交

| 哈希 | 提交说明 |
|------|---------|
| `abc1234` | {真实提交说明} |

### 测试

- [OK] {测试结果}

### 状态

[OK] **已完成** / # **进行中** / [P] **受阻**

### 后续步骤

- {后续步骤 1}
- {后续步骤 2}
```

---

**语言**：所有文档的自然语言内容使用**简体中文**；技术标识、路径、命令参数、真实提交标题和机器标记保留原样。


### 格式兼容与历史证据

- 新记录统一使用 `## 会话 N: 标题`、`**日期**: YYYY-MM-DD` 和 `**会话总数**: N`。
- 个人索引使用 `| # | 日期 | 标题 | 提交 | 分支 |`，文档表使用 `| 文件 | 行数 | 状态 |`。
- 读取器兼容旧版 `Session`、`Date`、`Total Sessions` 及中英混合记录；旧 4/5/6 列历史表头可更新为中文 5 列表头，历史行保留。
- 使用 `add_session.py` 生成 `<!-- trellis-session: ... -->` 身份标记，不手工构造或改写已有指纹。`@@@auto:*` 管理区标记也必须保留。
- 翻译历史日志仅调整可读文本，不更改原日期、分支、哈希、真实提交标题或验证事实。
